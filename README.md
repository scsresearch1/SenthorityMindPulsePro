# SenthorityMindPulsePro

MindPulsePro Phase 1 Kotlin app scaffold.

## Phase 1 coverage

- Enterprise-grade Kotlin + Jetpack Compose application architecture established in `app/`.
- Comprehensive screen framework implemented:
  - Dashboard
  - Live Physiology
  - Recovery
  - Stress & Emotion
  - Focus
  - Sleep
  - Fitness
  - Metabolic
  - Bio-Age
  - Gender-specific
  - Device & Data Quality
- A complete registry of 92 scientific parameters is represented using static/mock values.
- Each parameter is presented with simple, plain-language interpretability for fast understanding.
- Edge-state behavior included:
  - Building your baseline
  - Connect band
  - Collecting baseline
  - Updating
  - Stabilizing signal
  - Improving accuracy

## Notes

- App module package in this workspace: `com.mindpulse.app` (Kotlin + Jetpack Compose).
- Historical Phase 1 docs below refer to the broader MindPulsePro registry and navigation experiments.
- This is a static-data Phase 1 implementation aligned to the scientific UI vision.
- Next phase can connect real BLE/sensor pipeline and confidence/validation engines.
